//Part II Section 2 - DATA FILES

The folder "CSV FILES" contains 23 CSV files. Each of these files contains the data to be loaded into the database. 
In order to load the data into the database using SQLite, the instructions are as follows:

1. In the toolbar, go to "Tools".
2. In the dropdown, choose "Import".
3. In "Table to import to", choose "LibraryDatabase" as the database, and then choose the table you wish 
   to import to. Click continue.
4. In "Data source to import from", choose "CSV" as the data source type. For the options, choose the 
   input file corresponding to the table you are importing to (see list below), and a text encoding of
   "UTF-8". Click done.
