## Current Projects

- "survivor_pool_optimizer" is what I am currently working on now, albeit it is almost completed. It determines the optimal selection for a week's NFL survivor pool by solving a matrix of weeks and teams (the assignment problem) using the Hungarian algorithm. It also forecasts estimated pick distributions for future weeks and web scrapes future odds.

## Past Projects

- "deceptive_miss" is the most recent project I completed. Using some physics and geometric calculations, along with MLB Statcast data, I create a new statistic that calculates how long in a pitch's flight path it looks like it will be a strike (the projected strike percentage). The pitches that excel the most at this metric are labeled a deceptive miss. A leaderboard is created to see which pitchers were the best at this during the 2026 season. Some verification analysis later on using chase rate proves that this characteristic of a pitch is inducive of swings and misses from batters.

- "SQL_Database_Final_Report", along with the other projects in the repo, are ones I worked on at The Ohio State University, but they showcase more of my skillset as a data scientist. This one exhibits my SQL abilities; it is a creation of a transactional database, from the beginning relational database designs to the complex queries used to return data that has been requested.

- "CapstonePracProj" uses the nycflights13 dataset to draw conclusions into flight delays which is done using linear and logistic regression models. This was completed in my capstone course; other projects showcase even more technical ability, such as time-series forecasting and clustering algorithms, but cannot be shared due to sensitive data. Though the rest of my projects are in Python, this one was written in R.

- "Diabetes_Analysis" showcases the complete modeling process and creates a logistic regression model that predicts whether or not a patient has diabetes or not using a dataset from Kaggle.

- "Iris_Analysis" uses machine learning to predict a flower's species based on its measurements. It compares the performance of k-nearest neighbors (optimal k value determined using 10-fold cross-validation) to random forests and also implements Principal Component Analysis for dimensionality reduction.

- "Modeling_Explorations" experiments with building and evaluating neural networks and random forest models.
